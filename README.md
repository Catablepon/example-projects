# example apps and projects
Contains examples of simple apps made during frontend development and web server programming courses.  
React apps have screenshot folders that showcase usage.

- aida project folder contains a machine learning project
- express albums is a simple app to save album data. has features like validation and query options. authentication with json web tokens (refresh and access tokens)
- react movies is a simple app which pulls movie data from api and shows it. Includes trailer function.
- react nextjs fakestore is simple fakestore built with nextjs.
- react redux fakestore is simple fakestore with shopping cart functionality.
- react weather pulls weather data from api and you can favourite cities to show them on their own tab.
- reactnative map is a mobile app where you can input markers on a map
