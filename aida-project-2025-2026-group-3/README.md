## Project topic 

This project focuses on analyzing a large dataset of used cars in the United States. 
The dataset contains over 3 million used car details that was obtained in 2020. 
The goal is to find key factors that influence car sales through data preprocessing and machine learning methods. 
The project aims to provide data oriented insights, like sale price and sale time, 
to support car dealership chains decision making and possibly improve profitability.
