## Phase 1 (Business Understanding)

------------------------------------------------------------------ 

### Business objectives

The client is a car store chain that operates in the United States that wants to utilize data analytics to optimize pricing and selling of used vehicles. The objective of this data analysis is to provide insights into which cars sell fastest,  which features and brands affect price the most and what additional features increase vehicle value. 

By understanding the key factors that impact sales the client will be able to improve purchasing decisions and support demand forecasting. Initially it can improve customers profitability through machine learning models. 

------------------------------------------------------------------ 

### Current situation

The dataset contains 3 million used car details and it was obtained in 2020. In addition to the dataset customer has given requirements for the project that guide the data analysis and modelling process.  

Python as the primary programming language along with its data analysis and machine learning libraries (pandas, scikit-learn, TensorFlow) are used to achieve the goals. Team members implement skills gained during previous AI/DA module courses such as machine learning and data preprocessing. The workload of each team member will be discussed across different phases of the project. 

------------------------------------------------------------------ 

### Initial goals of data analysis and modelling

The initial goals of data analysis are explore the dataset, identify the features, preprocess data and (handle NaN values and outliers) and to prepare the dataset for use in machine and deep learning models. 

In the modelling phase we aim to create a model or models that help the customer understand which features affect the price of used vehicles, identify which cars can be sold more easily and predict the price of a used vehicle based on its features. 

------------------------------------------------------------------ 

### Project goals

The overall project goal is to understand the dataset, process the data and create a complete machine or deep learning model based on it that meets the customer's requirements. The models performance and accuracy will be evaluated using metric tools like accuracy. The project will be presented in a seminar and a final report will be submitted at the end of the course.
